# Java DSA Working Notebook

Personal repository containing my daily Java implementations of Data Structures, Algorithms, and Object-Oriented Programming concepts.

---

## 📝 What This Repository Is

This is my personal practice ground and learning archive. It is structured to help me:
1. Implement fundamental algorithms and data structures from scratch in Java.
2. Analyze Time & Space complexity on paper and verify the behavior through code.
3. Archive LeetCode problem solutions alongside their optimization notes and common traps.

The directory structure below reflects the modular packages maintained across my learning journey.

---

## 📂 Directory Structure

```text
src/
├── basics/               # Fundamental math, loops, and introductory logic
├── oops/                 # Object-Oriented Programming (Abstraction, Encapsulation, Inheritance, Polymorphism)
│   ├── abstraction/      # Abstract classes, interfaces, and contracts
│   ├── encapsulation/    # Data hiding and state validation
│   ├── inheritance/      # Class hierarchies and method overriding
│   └── polymorphism/     # Overloading and dynamic method dispatch
├── collections/          # Java Collections Framework (List, Set, Queue implementations)
├── complexity/           # Big-O asymptotic analysis notes
├── sortingAlgo/          # Standard comparison-based sorting algorithms
├── binarySearch/         # Binary Search implementations and boundary patterns
├── bitwiseOperator/      # Bitwise manipulation and binary logic
├── strings/              # String algorithms and sliding window drills
├── recursion/            # Recursion call stack traces, include-exclude patterns, and notes
├── arrayQuestionSolving/ # Array-focused problem solving
└── leetcode/             # Standalone LeetCode solutions with approach breakdowns
```
